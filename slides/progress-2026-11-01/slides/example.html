The agent never sees the tests. FrontierMemory rewrote the public task's prompt to drop the function signature and file path, so a run without memory has to guess the interface. In the main study every no-memory Word2Vec run failed because the grader could not find or load the expected function. The empty-list case is the other trap: the reference solution special-cases it and returns an untrained Word2Vec model.
