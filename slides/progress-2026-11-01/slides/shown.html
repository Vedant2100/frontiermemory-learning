Finding · shown or sought?

The agent only sees 10,000 characters of memory. The rest it has to go look for.

Shown

Codex injects the first and last 5,000 characters of the index. In M3 that is 83 of 324 topics, and no Word2Vec topic.

Sought

On Word2Vec, all 10 memory runs searched the folder themselves and found the right notes. On awilix, almost none did.

Both happen in the same memory run. Nothing is switched off; searching is up to the agent.

We predicted M3 wouldn’t help on Word2Vec. It went 5/5. We report that as a failed prediction.

This is the mechanism story of the paper: memory reaches the agent two ways, and agents only search when the task cues them.
