The main study

Three conditions, planned in writing before any result

A0

No memory

R25

Memory from a random 25% of past runs

M3

Memory from all past runs

7 tasks × 3 conditions × 5 trials = 105 trials. Fixed order, fixed analysis. Only the memory folder differs.

Preregistration means the design, memories, trial order and statistical tests were committed before any confirmatory trial. Later changes are dated amendments.
