Memory flow at task time

How memory reaches the agent

Per FrontierMemory’s Codex adapter: the folder is copied to ~/.codex/memories before the run and deleted after

Two paths from the same folder in the same run. Shown: Codex puts memory_summary.md (a copy of our MEMORY.md) into its developer instructions, truncated to the first and last 5,000 characters, which covers 83 of 324 M3 topics. Sought: every other file sits on disk and the agent can open it with shell commands; on Word2Vec all 10 memory runs did. The no-memory control runs the same Codex with the memories feature on but no folder, so the folder is the only difference. Memory is built beforehand by our 4-step pipeline (notes, groups, topic files, index) using the official FrontierMemory instruction; rules at github.com/letta-ai/frontiermemory/blob/main/docs/rules.md.
