How the memory is built

No human writes it. The same local model does, in four steps.

1

Notes

One per past run: what was tried, what worked.

2

Group

Notes on the same topic go together.

3

Topics

One file of lessons per group, citing its sources.

4

Index

MEMORY.md points to all topic files.

Every model call gets the official FrontierMemory instruction, unchanged. Each memory is frozen by hash before use.

The full-corpus memory has 324 topic files. The smaller one, R25, is built the same way from a random 25% of the past runs.
