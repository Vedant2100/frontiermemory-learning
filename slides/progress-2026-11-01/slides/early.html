DAPT task

gone

An early gain vanished when re-run.

Why: memory raised tests passed (18.7 → 30.3 of 37), but a run only counts if all 37 pass. Main study: 0, 1, 0 of 5.

DAPT numbers: first A/B (3 runs each) averaged 18.7 vs 30.3 tests of 37; a repeat with the same memory reversed it (23.7 without vs 20.7 with). These early runs shaped the design: a single small A/B can mislead, so we preregistered a bigger study before running it. DAPT details from the public SkillsBench task (tasks/dapt-intrusion-detection): the agent gets packets.pcap (DAPT2020 subset) and a template CSV, and must compute protocol counts, packets per minute, packet sizes, IP/port entropies, IP-graph stats, inter-arrival times, producer/consumer counts, 5-tuple flow counts, and true/false flags for benign traffic, port scan, DoS and beaconing. Counts must be within 1%, entropies within 5%, flags exact; any miss fails the run. FrontierMemory's version (dapt-intrusion-detection-workflow-learning) is adapted from this.
