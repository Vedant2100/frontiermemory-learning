The question

The leaderboard doesn’t report a “no memory” row

What FrontierMemory gives

674 past agent runs, a fixed instruction for turning them into memory, and 15 new tasks with hidden graders.

What it doesn’t report

How the same agent does without memory. The protocol defines that control run, but the public leaderboard never shows it. A high score could just be a strong agent.

FrontierMemory’s README and rules define a no-memory control (same task agent, no memory folder), but frontiermemory.com, checked Nov 1, shows no no-memory row, no per-task results and no standard deviations. The benchmark ranks memory systems against each other. We add the missing baseline: same agent, same tasks, memory on or off. Next slide: one of the 15 tasks, exactly as the agent and grader see it.
