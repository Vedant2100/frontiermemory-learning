The question

The leaderboard has no “no memory” row

What FrontierMemory gives

674 past agent runs, a fixed instruction for turning them into memory, and 15 new tasks with hidden graders.

What it doesn’t show

How the same agent does without memory. A high score could just be a strong agent.

The benchmark ranks memory systems against each other. We add the missing baseline: same agent, same tasks, memory on or off. Next slide: one of the 15 tasks, exactly as the agent and grader see it.
