Setup

Agent tools and grader checks

Agent · Codex + Qwen3.8-27B

  • Gets: the task prompt, inside the task’s own container.
  • Tools: a shell, so it can run commands and read, write and test files. Web search is off.
  • Memory: the folder sits in ~/.codex/memories. MEMORY.md goes into its instructions; it can open the other files.
  • Limit: one attempt, with a time limit per task (20 min on Word2Vec).

Grader · hidden verifier

  • When: after the agent stops, in a separate container.
  • Sees: only what the agent left behind, e.g. /workspace/solution.py. The agent never sees the tests.
  • Checks: the task’s own tests. Word2Vec: a file check plus 5 cases on the returned model.
  • Score: every check passes → 1, anything else → 0.

a task counts only if its reference solution passes our setup (7 of 15 do)

Agent details follow FrontierMemory's Codex adapter (src/frontier_memory/agents/codex.py): memories feature on in every run, including no-memory, so the memory folder is the only difference; web search disabled. Grader details follow the Harbor task format (tests/ run by the verifier, reward 1 or 0). Docker isn't available on the cluster, so we run the official task images in Apptainer and validate each task's grading path with its reference solution first.
