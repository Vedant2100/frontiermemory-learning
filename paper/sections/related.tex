\section{Related Work}
\label{sec:related}
\textbf{Experience memory for agents.}
Coding and general agents accumulate procedures, skills and lessons across tasks~\cite{survey-selfevolving,sepm,chronos}.
Several systems gate admission or retention of such lessons with evidence or verifier signals~\cite{grounding-memory,memguard,sedm,aecg}.
Our audit asks the prior question of whether the generated lessons are grounded in their cited evidence at all, and shows that simple automatic checks fail validation on a local model.

\textbf{Evaluating memory.}
VibeMemBench~\cite{vibemembench} finds that most memory configurations fail to beat no memory on repository tasks.
Scope Before You Persist~\cite{scopebefore} shows that lessons can harm tasks outside their scope.
FrontierMemory~\cite{frontiermemory} standardises corpus, instruction and verifiers but omits a no-memory row.
We add that row under preregistration, and we separate memory that the harness shows from memory that the agent seeks.

\textbf{Organisational memory.}
Shared memory across agents and teams is studied as organisational learning~\cite{survey-collective,enterprise-memory}.
The FrontierMemory corpus is an instance of it: prior runs, often by other agents, distilled for a new one.
